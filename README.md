# 广东高校教师岗前培训「两学」刷题练习

广东省高校教师岗前培训《高等教育学》《高等教育心理学》（"两学"）自编刷题练习卷，纯前端单页、离线可用，做答记录仅存于浏览器本地。

## 在线使用

- **高等教育学**：<https://icgma.github.io/psy-quiz/jiaoyuxue.html> —— 卢晓中《高等教育新论》，118 题（单选 70 · 判断 27 · 简答论述 14 · 案例分析 7），依据培训划定重点章节从教材原文整理命制
- **高等教育心理学**：<https://icgma.github.io/psy-quiz/> —— 张积家《高等教育心理学》（第二版），112 题（单选 60 · 判断 29 · 举例说明 14 · 案例分析 9）

两卷页头可互相切换。

## 考情

广东"两学"为全省统一命题闭卷考试，约 2 小时，满分 100 分、60 分合格，成绩是申请高校教师资格认定的必要条件（有效期五年）。

## 功能

- 单选/判断即时判分，正确答案高亮 + 解析
- 客观题乱序刷题，错题自动进错题本，答对移出、可单独重做
- 简答/案例分析配答题卡输入区，可先作答再对照参考答案并自评
- 进度自动保存在浏览器 localStorage
- 「考情速览」页整理各章考点分布与答题要领

## 开发

`index.html`（心理学）与 `jiaoyuxue.html`（教育学）均为无依赖单文件 HTML；中文名文件为本地源稿（见 .gitignore）。修改后提交推送即可，GitHub Pages 自动部署。
