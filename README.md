# 高等教育心理学 · 刷题练习卷

广东省高校教师岗前培训《高等教育心理学》自编练习卷（纯前端单页，离线可用）。

- **教材依据**：张积家主编《高等教育心理学》（第二版），高等教育出版社
- **考情**：广东“两学”全省统一闭卷考试，约 2 小时，满分 100、60 分合格
- **题型**：单选题 38 · 判断题 18 · 举例说明 10 · 案例分析 7，共 73 题，全部附答案与解析

## 功能

- 单选/判断即时判分，正确答案高亮 + 解析
- 客观题乱序刷题，错题自动进错题本，答对移出、可单独重做
- 举例说明/案例分析配仿答题卡输入区，可先作答再对照参考答案并自评
- 做题进度自动保存在浏览器 localStorage，关掉页面下次接着刷
- 「考情速览」页整理常考点分布与答题要领

## 使用

直接打开 [GitHub Pages 在线版](https://icgma.github.io/psy-quiz/)，或下载 `index.html` 双击离线使用。

数据不出本地：所有作答记录仅存于本机浏览器，不上传任何信息。
